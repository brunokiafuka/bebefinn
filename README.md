# Bebefinn

An underwater learning game for ages 2–3, built with three.js. Swim with Finn the fish and learn numbers, counting & simple maths, the alphabet and first words.

- 4 worlds × 5 stages, each stage harder than the last; stars unlock the next stage
- Spoken prompts, big touch targets, hints after a pause, no fail states
- Installable PWA that works offline (add to home screen on a tablet)

Run locally: `python3 -m http.server 8080` and open http://localhost:8080
